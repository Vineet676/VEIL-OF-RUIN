ASHEN CROWN — STAGE 3: THE COLLAPSE

Theme:
Crumbling ruins / falling citadel / toxic machinery

Mood:
Chaotic, unstable, decaying and dangerous.

Place this folder under:
res://assets/environments/stage_3/

Folders:
background/  Far parallax layer
midground/   Middle parallax layer
foreground/  Front parallax layer
tiles/       Terrain/wall/decor tile atlases
platforms/   Traversal platform atlas
obstacles/   Hazards
props/       Scene/interactable props
structures/  Broken architecture
water/       Toxic liquid
mechanical/  Machinery and gears
details/     Debris/decals
lighting/    Lamps and environmental light sources

The generated artwork is supplied as separated category/atlas PNGs.
The tile/platform sheets should be treated as atlases; the original
full reference sheet should not be used as one gameplay texture.

Suggested Godot parallax:
background -> 0.05–0.15
midground  -> 0.25–0.45
foreground -> 0.8–1.15
gameplay   -> 1.0
